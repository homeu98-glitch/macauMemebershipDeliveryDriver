# 車手功能摘要

## OTA 更新

- App 啟動時會自動檢查最新版本
- `我的` 頁面提供手動 `檢查更新` 按鈕
- 若有新版本，會顯示更新提示並導向 `/apkdownload`

## 車手公告

- 後台可在 `公告發布` 發布給全部車手的公告
- `我的` 頁面在進入時會自動刷新公告
- `我的` 頁面也提供 `刷新公告` 按鈕，避免推送或同步延遲時看不到最新內容

## 地區篩選

- 首頁頂部提供 `取貨地區` 與 `送達地區` 雙欄位篩選
- 篩選完全在 App 本地端完成，不重新查 server
- 商戶與客戶 district 由後端根據澳門 GeoJSON 預先寫入

## 交易編號

- 訂單新增可讀交易編號 `transaction_code`
- 格式：`T + YYYYMMDDHHmmss + 10 位 sequence`
- App 與後台顯示時優先使用 `transaction_code`

## 接單回饋

- 車手點擊 `接單` 後，按鈕會進入 loading 狀態
- 顯示 `接單中...` 與進度圈
- 同時禁用重複點擊，降低連點造成的誤解與重複請求

## 導航

- 導航按鈕優先使用高德地圖原生座標導航 scheme
- 直接以經緯度作為目的地，避免 URI 編碼文字干擾定位

## 微互動與氣氛

- 首頁新單卡片加入進場滑入與短暫高亮效果
- 接單按鈕加入 loading 圈與 `接單中...` 提示，避免重複點擊
- 進行中訂單的階段條加入輕微脈動動畫
- 完成配送時會短暫顯示獎勵提示 banner
- 空狀態改成更友善的插畫式提示
- 下拉刷新改為可愛的車手騎車動畫
- 通知列小圖示改為專用 notification icon，避免 Android 預設機器人圖示
