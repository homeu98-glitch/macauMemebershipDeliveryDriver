macau-ledger ↔ SiteB API 規格 v3

這份文檔提供給 macau-ledger 對接使用。內容以目前已實作的最新行為為準，重點涵蓋：建單、查單、callback、圖片訂單、沒有客戶資料的匿名訂單，以及 callback 內統一的車手資料 / 接單 GPS。

Production Base URL: https://macau-delivery.vercel.app clientId: macau-ledger 建單支援 images[] callback 全事件帶 driver + acceptanceLocation

更新重點

  • POST /api/v1/orders 現在支援 images[]，第一版接受公開可下載 URL。
  • customer 不再要求一定要有完整姓名、電話、文字地址。
  • 若沒有 customer.address，至少要提供一張 images[].url，讓車手可打開圖片查看地址與聯絡資料。
  • 所有 callback event 都會統一帶 driver.fullName、driver.phone、acceptanceLocation。

授權

POST /api/v1/auth/token

先用共享憑證換取 JWT，再以 Bearer Token 呼叫其他 v1 API。

參數

欄位必要型別說明
clientId是string目前固定使用 macau-ledger
clientSecret是string雙方約定的共享密鑰
audience否string建議填 siteb-api

Request example

{
  "clientId": "macau-ledger",
  "clientSecret": "SITEB_DELIVERY_CLIENT_SECRET",
  "audience": "siteb-api"
}

Response example

{
  "success": true,
  "accessToken": "<jwt>",
  "tokenType": "Bearer",
  "expiresIn": 3600
}

建單

POST /api/v1/orders

這個 API 依 externalOrderId 做冪等處理。重送同一張單不會重複建單，只會更新 callback / 圖片 / 客戶快照。

必要欄位

欄位必要型別說明
externalOrderId是string外部唯一訂單編號，不可重複使用
pickupMode是stringnow / scheduled
deliveryMode是stringnow / asap / scheduled
deliveryFeeMop是number配送費金額
shop.name是string店舖名稱
shop.address是string店舖地址
shop.latitude是number店舖座標
shop.longitude是number店舖座標
callback.url是stringSiteA / macau-ledger 接收 callback 的 URL
客戶資料現在採「可缺」策略：customer.address 不是必填，但如果沒有文字地址，必須提供至少一張 images[].url。

可選欄位

欄位型別說明
pickupTimestring \| null預約取貨時間
deliveryDeadlinestring \| null預約送達時間；當 deliveryMode=scheduled 時必填
urgentboolean是否急單
currencystring預設為 MOP
customer.namestring \| null客戶姓名，可缺
customer.phonestring \| null客戶電話，可缺
customer.addressstring \| null客戶地址，可缺；缺少時建議用圖片承載地址
customer.latitudenumber \| null客戶座標，可缺
customer.longitudenumber \| null客戶座標，可缺
customer.deliveryNotestring \| null補充說明
images[]array訂單附圖，供車手在網頁端查看
images[].urlstring公開可下載圖片 URL
images[].labelstring \| null圖片說明，例如「門牌照片」
images[].mimeTypestring \| null例如 image/jpeg
items[]array商品明細，可缺
notesobject附加資訊，可缺

Callback

SiteB 在訂單狀態更新後，會對建單時提供的 callback.url 發送 POST。所有 callback 都會統一帶 driver 和 acceptanceLocation。

Header

Content-Type: application/json
x-siteb-signature: sha256=<hex>
若建單時有提供 callback.secret，簽章會優先用該 secret；否則回退到系統預設 webhook secret。

共用欄位

欄位型別說明
eventTypestring事件名稱，例如 order.accepted
externalOrderIdstring對應外部訂單編號
eventTimestringcallback 發送時間（ISO-8601）
statusstring當前訂單狀態
driver.fullNamestring車手姓名
driver.phonestring車手電話
acceptanceLocation.latitudenumber \| null接單 GPS 緯度
acceptanceLocation.longitudenumber \| null接單 GPS 經度
acceptanceLocation.capturedAtstring \| null接單 GPS 取得時間
acceptanceLocation.sourcestringdriver_accept_action / driver_locations_fallback / unknown

實作建議

  • 若是圖片單，請在接單 UI 顯示縮圖，並讓車手可點開圖片查看地址與補充內容。
  • 若 customer.addressProvided = false，車手端不應強制使用導航，而應提示「請查看圖片」。
  • callback 接收方請以 additive 方式解析新欄位，不要假設只有舊 payload。

車手在線 / 地區查詢

GET /api/v1/drivers/presence

提供給 macau-ledger / 商家顯示用的「有效在線」與「地區」查詢。

嚴格規則：地區必須在同一個有效在線窗口內（預設 3 分鐘）。車手雖然有效在線，但若 3 分鐘內沒有定位，會歸類到 unknown。

Query

欄位必要型別說明
includeDrivers否stringtrue/false，預設 true。若設為 false，只回傳各區統計。
